# Version and new features

Imported research dated October 10, 2026. A Photoshop 2026 window was observed; its full build number was not checked.
A Windows application name alone does not prove a feature is available.

The imported research reports that [Adobe What's New](https://helpx.adobe.com/photoshop/desktop/whats-new/whats-new-in-adobe-photoshop-on-desktop.html),
updated October 5, 2026, lists Enhance Edge and GPT Image 2 generation/editing under September 2026 v27.11.
This translation does not independently reverify those claims. Distinguish beta features from stable desktop releases.
For each actual task, check relevant official help and Help > About Photoshop; do not update the application on your own.

## Feature decisions

| Feature | Possible use | Check first |
|---|---|---|
| Contextual Task Bar | Relevant selection/masking/placement commands | Contents vary with active layer and selection. |
| Generative Fill | Requested background or selected scene changes | Visible model, account access, source transfer and credit terms. |
| Generative Expand | Generate surroundings for a requested crop | Surroundings rather than the design/logo; version-specific help. |
| Enhance Edge | Reduce background color in mask edges | Application access and generative credit cost. |
| Prompt to Edit / partner models | Requested generative editing | Current official documentation and live model list. |

[Generative Fill help](https://helpx.adobe.com/photoshop/desktop/create-open-import-images/create-images/edit-images-with-generative-fill.html)
describes selection, model/prompt in the Contextual Task Bar, Generate and variant selection.
Do not freeze a documentation model list into permanent assumptions; verify visible options for the account/version.
Mentioning a model in a skill file does not install it.

[Enhance Edge help](https://helpx.adobe.com/photoshop/desktop/create-masks/layer-masks/use-enhance-edge-to-refine-masks.html)
describes edge refinement with a selected layer mask. The imported October 5 report states a cost of 20 generative credits per use.
Verify the current application cost before execution and follow user scope and mandatory tool approval rules.
Account access, credits and the feature were not actually tested here.

Generative editing does not replace preserving the actual design. Use native layers/smart objects for protected brands, product lettering and logos.
Cloud/AI operations remain cloud operations even when desktop editing was selected.
If a requested feature is unavailable, use a verified conventional Photoshop method or explain the specific limitation.
