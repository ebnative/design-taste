# Design Taste

## Studio coordination
Follow the [private project-record contract](references/project-record.md) and [translation table](references/translation-table.md). Design Taste alone writes DESIGN.md and direction tokens in MOTION.md. Disciplines append Proposed change entries in PROCESS.md; only the brain resolves them and updates direction.

1. Establish BRIEF.md: audience, meaning, exact deliverables, constraints, approver and a bounded definition of done.
2. Develop shared direction. Read only relevant atlas records; separate sourced history, observations and proposals.
3. Where showroom families exist, offer only original executed-verified cards explicitly marked presentable by Ebru. A selected family seeds DESIGN.md; do not invent a selection or fill missing cards with third-party inspiration. If no eligible family exists, develop an original provisional direction and request the actual choice when needed.
4. Dispatch the needed graphic-design, web-ui-design and motion-design work with exact tokens. Disciplines translate direction, not set it. Use only the disciplines the task needs.
5. Integrate discipline critique and a separate cross-discipline coherence review. Resolve proposals in PROCESS.md and propagate accepted changes.
6. For production, select operation routes that are verified and present in the live inventory; record outputs and evidence in EXPORTS.md. An unverified route may be planned, not promised. Preserve editable masters and distinguish rendered previews from native files and human acceptance.

## Graphic art direction (retained until discipline migration)
Turn a brief into reasoned visual decisions. Identify intended meaning, medium, references and existing choices without repeating answered questions.
Read the [cover workflow](../../workflows/cover-editorial.md) for personal covers.
Retrieve only relevant atlas records through the [shared guide](references/shared-design.md).
Present historical sources, observable principles and contemporary proposals separately.
Do not automatically assign a movement label to a person's identity; explain why a proposal fits this task.
Preserve the chosen visual direction in DESIGN.md. Use the appropriate Designer skill for actual Adobe production.
This skill provides no application connection. Use Art & Design Atlas for learning and Design Critic for existing-work critique.

## Operational and evidence boundaries
Use the [identity workflow](../../workflows/identity.md) for identity systems and the [original example](../../examples/learning-guide-cover/README.md) for project-owned cover learning. Freeze exact copy, languages/scripts, dimensions, required uses, assets/fonts and approver. Preserve distinct concepts/rejections, optical refinement and actual full/reduced flat views. Label provisional choice versus actual human acceptance; never infer private preferences or profile memory from a pilot.

This package provides sourced knowledge and task-specific proposals, not professional tenure, a degree, mastery or expert/audience endorsement. Report authored curriculum, source-reviewed claims, inspected artifacts, software tests, independent reproduction, native operations and human acceptance separately. Source review confirms named passages, not rights or all corpus claims. Screen assets/fonts separately; unknown permission is not automatic clearance/license.

Check exact glyphs, typography/spacing, fallback and actual required sizes. For unfamiliar scripts/cultural symbols, declare uncertainty and require appropriate qualified review; no universal style hierarchy. Lexical results do not solve a brief and constraints are not evaluated. Missing images/sources/tools require explicit abstention on affected properties, preserving useful supported work and failure receipts.

Native handoff must preserve Windows adapters and protect unsaved documents. Current-wave Photoshop is blocked by user decision; no launch/control, installation or JSX workaround. Editable SVG is not Adobe-native proof. No affected safety/rights/production failure may be averaged into aesthetic success.
