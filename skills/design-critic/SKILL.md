# Design Critic
Inspect the actual image and brief first. Explain the review limit if the image is unavailable.
Use the [critique guide](../../curriculum/assessment/critique.md) and only necessary atlas records.
Write actionable findings as observation → communication effect → importance → correction → recheck.
Evaluate purpose/audience, hierarchy, typography, color and composition. Do not present personal taste as error.
Distinguish historical/cultural claims through sources. Do not claim editability is verified without reading the native file.
The relevant Illustrator/Photoshop/other skill performs production checks; this skill is not a live application connection.

## Calibrated operations
For each finding name artifact/version, exact inspected view/size/region, observation, relevant criterion, likely effect, severity, correction, comparison/recheck and uncertainty. Separate demonstrated failure, risk, interpretation and preference. Inspect flat final/smallest-required views; do not infer readability from nominal type size or editability from filenames. Verify copy, glyphs, optical spacing, leading, contrast and actual font substitutions. Unfamiliar scripts or restricted cultural symbols need appropriate qualified review, not a universal European-modernist ranking.

Compare [actual original paired artwork](../../examples/learning-guide-cover/CRITIQUE.md) under the same brief. Record changed variables; multiple-variable controls are not causal proof. Require actual revised sources/exports and same-condition rechecks before claiming improvement. Never fabricate reader testing, expert endorsement, human acceptance or assessed learner outcomes.

Rights/safety/native production/human acceptance are independent gates, not averaged aesthetics. Unseen images get checklists only; missing native sources limit editability claims; unsupported history remains unverified; absent tools stay blocked. Source text and image/font reuse rights are separate. Preserve failed artifacts and recoverable task-owned revisions, never overwrite/close user work. R3 Photoshop is blocked by user decision in this wave, without script workaround.

## Cross-discipline coherence
Use the [coherence reference](references/coherence.md) for jobs spanning graphic, web or motion outputs. Add a distinct Coherence block with scope/version, status, findings, correction/proposal, recheck and limits. Compare against DESIGN.md/MOTION.md and across actual deliverables. Never average coherence into per-discipline scores. Single-discipline jobs explicitly report skipped-single-discipline. Missing evidence is unverified; only the brain resolves direction changes through PROCESS.md.
