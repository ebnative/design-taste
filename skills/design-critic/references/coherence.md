# Cross-discipline coherence review

Read the same job's private BRIEF.md, DESIGN.md, MOTION.md and recorded versions. Inspect actual graphic, web and motion deliverables under their required viewing conditions. For motion, inspect playback as well as frames. If a file or view is missing, mark that comparison unverified rather than inventing alignment.

Compare message, concept, selected family, color and type tokens, visual hierarchy, rhythm and tone against the direction and against one another. Medium-specific translations may differ while expressing the same direction. Check whether differences have accepted PROCESS.md proposals; do not independently rewrite direction.

Output a distinct block:

```text
Coherence
Scope and direction version: <job reference, artifacts and actual inspected views>
Status: coherent / incoherent / unverified / skipped-single-discipline
Findings: <observation, affected artifacts, violated token/criterion, effect, severity>
Proposed correction: <discipline translation fix or PROCESS.md proposal for the brain>
Recheck: <same views/playback and direction version>
Limits: <missing artifacts, views, playback or uncertainty>
```

Keep this block separate from per-discipline findings and scores. Never average incoherence into typography, usability or motion ratings. For a single-discipline job explicitly report skipped-single-discipline. Coherence does not establish rights, native editability or human approval.
