# Production operation routes

routes.json records operation-specific candidate routes, hosts, status and evidence. An adapter's imported history or source documentation is not current execution proof. Every route starts unverified except Photoshop desktop-control, which remains blocked by the recorded user decision. The same route ID may occur under multiple operations; verification applies only to the tested operation.

A verified route needs a dated record of the matching executed operation and an inspected output. The registry validator checks record references and metadata, not the truth of an approval or visual quality; inspect the actual record before selection. The brain must also discover the route in the current live tool inventory. Schema success alone never authorizes execution.

Adobe for Creativity remote MCP remains unregistered and untested until P0-10's account/OAuth/test gate. Claude Desktop is an unverified cloud fallback. Native layered work still requires the relevant desktop route. Photoshop remains blocked until P0-11 records Ebru's explicit decision; do not substitute terminal/AppleScript/ExtendScript routes.
