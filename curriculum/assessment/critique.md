# Design critique

Read the brief, audience and desired feeling first. Inspect the result and actual preview.
Observation → communication effect → importance → proposed change → recheck.
Assess brief/meaning, visual organization, historical/cultural context, editable production and process separately.
Personal taste is not objective error. Do not produce findings about an image you have not seen.
A score or search ranking does not prove design quality. Technical checks do not replace aesthetic judgment.

## Evidence-required findings

Each finding records artifact/revision, inspected flat view and pixel/use size, exact region/text, literal observation, applicable brief criterion, likely communication effect, severity, proposed correction, actual comparison/recheck and uncertainty. Classify as demonstrated failure, risk/uncertainty, interpretation or preference. Audience effect without real testing is a hypothesis. Never claim expert, reader or community endorsement from AI inspection.

Separate brief/content, hierarchy/typography, composition/color, contextual history, rights/safety, editability/production and human acceptance. A blocking right, save failure, required-use defect or safety failure cannot be averaged away. If no demonstrated defect exists, state that instead of manufacturing one. Search scores describe lexical relevance only.

## Required views and typography

Inspect flat artwork at final and smallest brief-required sizes; mockups are supplementary. Compare exact copy and punctuation, glyph coverage, kerning, leading, margins, optical alignment and actual contrast. Record requested/actual fonts and substitutions; size values in a source are not measured readability. Screen contrast evidence does not automatically certify print or raster-cover WCAG conformity. Native inspection is required only when native editability is claimed; SVG is not PSD proof.

## Comparison, revision and advancement

Use the same brief/views for [original A/control examples](../../examples/learning-guide-cover/CRITIQUE.md). The control is not client work; multiple variables changed, so no single-variable causal proof. Require a retained before, actual revised source/export, specific change and same-condition recheck. A proposal alone does not advance a learner. Review each observable module criterion against submitted evidence; missing mandatory artifacts lead to revise/blocked/not-assessed, not a taste score or degree-equivalence outcome. No learner submissions have been assessed by authoring this curriculum.

## Context and abstention

Name tradition/place/period/language/audience only when supported. Explain source context before adaptation; avoid culture-as-decoration and universal European-modernist standards. Unfamiliar scripts, sacred/restricted symbols and identity-sensitive uses require qualified contextual review; do not invent community authority.

Unseen image: provide a checklist, no pixel findings. Missing source: critique visible output only, editability unverified. Unsupported historical claim: qualify/remove it. Unavailable native route: blocked, not simulated. Missing approval: human pending. Unknown rights: affected asset redistribution unresolved; original replacements permitted without clearance claims.

## Recovery

Keep original/rejected routes and failure receipts. Use new task-owned versions, protect unsaved documents, never overwrite another person's files, silently replace fonts or close unrelated documents. Save/reopen/export failures stay separate from aesthetic evaluation. This wave's Photoshop native gate is blocked by user decision; do not execute scripts to bypass it.
