# Personal covers and editorial direction
Explore which aspects of themselves the user wants to express, beyond a ready-made movement label.
Start with one concrete question: what feeling or thought should stay with the viewer? Do not repeat existing answers.
Intended idea → visual metaphor → composition → color relationships → typography → production method.
Present identity/metaphor proposals as assumptions; do not infer a psychological profile.
Retrieve 2–4 relevant atlas records. Explain sourced history separately from today's design proposal.
If the brief is sufficient, propose meaningful directions with a central idea, visual arrangement, rationale and risk for each.
Record the selected direction in DESIGN.md and rejected directions with reasons in PROCESS.md.
Once dimensions, medium, final text, assets and delivery conditions are clear, hand off to the production skill.
Do not generalize a preference for one cover to all of the person's work.

## End-to-end operations

1. Brief: input audience/message/content and existing decisions; output BRIEF.md with exact copy, dimensions, medium, required full/reduced sizes, language/script, font/asset constraints and approver. Exit: no invented psychological profile or missing required text; project-owned briefs do not require private personal data.
2. Research/rights: input 2-4 relevant records and actual passages; output exact claim/source/page/locator/date/limits plus separate asset/font rights inventory. Exit: cite supported history, label contemporary proposals, exclude unsupported assets; institutional hosting is not a reuse license. See [cover decisions](../atlas/foundations/editorial-cover.md).
3. Concepts: input frozen brief; output three materially distinct editable directions and flat views, each with metaphor, hierarchy and risk. Exit: distinct composition or idea, not recolorings; all required copy present. Record alternatives, rejected routes and provisional reasons in PROCESS.md.
4. Selection: input same-size comparison; output DESIGN.md with author recommendation versus actual human selection. Exit: unresolved human choice remains pending, not approval inferred from authorship.
5. Refinement: input selected editable source; output typography/optical checks and before/after revision evidence. Exit: exact copy, glyph coverage, line breaks, margins, kerning/leading, clipping and actual required-size contrast inspected. Nominal sizes are not readability results. Check fonts/fallback; unfamiliar scripts require qualified review, not Latin-only confidence.
6. Export: input stable source and delivery constraints; output EXPORTS.md, flat full/reduced files and editable master. Exit: dimensions/formats read back, no crop/collision at required sizes; print spine/bleed/profile only if actually specified and tested. Mockups supplement flat artwork, not replace it.
7. Critique: input actual views and source availability; output criterion-separated findings, tradeoffs and rechecks using [assessment](../curriculum/assessment/critique.md). Exit: source-only facts, pixel observations, interpretation, preference and uncertainty distinguishable; proposed revisions not called executed improvement. No magical taste score.
8. Native/human gates: input authorized application route and designated reviewer; output reopened native-layer/export receipt and explicit human decision or pending/blocked. Exit: native proof is separate from SVG/PNG/software tests. This wave's Photoshop R3 is blocked by user decision: no application launch/control, installation or script workaround; preserve legacy Windows route. Human acceptance is not tool success.

## Error recovery and context

On missing image, abstain on visual findings. On missing source, native editability is unverified. On font substitution, wrong target, unexpected save prompt or failed reopen, stop affected delivery; preserve originals/partial outputs and failure receipts. Only new task-owned documents/paths; never close, overwrite or discard unrelated unsaved work. Recheck fresh corrected exports, not a polished mockup of an obsolete revision.

Geometric restraint, dense imagery and expressive lettering can each serve particular briefs. Do not rank cultures/styles universally. Require contextual support for historical/cultural claims and appropriate language/community review for unfamiliar scripts or restricted symbols.
