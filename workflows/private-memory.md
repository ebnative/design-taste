# Özel hafıza
Kişisel tercihleri paylaşılabilir repoya yazma. DESIGN_TASTE_PRIVATE_ROOT ortam değişkeni veya
kullanıcının belirlediği repo dışındaki özel proje alanını kullan. Yoksa bu oturumda kararları tut;
kalıcı kayıt yaptığını iddia etme. Kurulu eski skill'in style/memory klasörünü geçiş öncesi koru.
Kayıt alanları: person_id, project_id, asset_id, scope, feedback_date, evidence, preference, supersedes.
Yalnız açık kullanıcı geri bildirimi/onayı kanıt oluşturur. Model önerisi tercih değildir.
Tek işin onayı o işin onayıdır; tüm biçimsel ayrıntılara ilişkin genel tercih değildir.
Kişiler ayrı kimlikler taşır; bilinmeyen kişiye tercih atama. Yeni düzeltmenin kapsamını koru.
