# Private memory
Do not write personal preferences into the shareable repository. Use DESIGN_TASTE_PRIVATE_ROOT or
a user-designated private project area outside the repository. Otherwise retain decisions only within the session;
do not claim persistence. Preserve an existing installed skill's style/memory directories before migration.
Record fields: person_id, project_id, asset_id, scope, feedback_date, evidence, preference, supersedes.
Only explicit user feedback/approval constitutes evidence. A model suggestion is not a preference.
Approval of one work applies to that work, not every formal detail as a general preference.
Keep people under separate identities; do not assign preferences to an unknown person. Preserve the scope of new corrections.
