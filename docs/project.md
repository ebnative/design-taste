# Project identity and scope

Project ID: `design-taste`\
Product: Design Taste\
Maintainer: `ebnative`\
Status: working initial release, `0.1.0`\
Profile: Python scripts + skill packages + sourced knowledge base\
Project standard: `1.0.0`, adopted by the user on October 10, 2026

## Problem and user task

Make art and design knowledge searchable, teachable and applicable to personal portfolio work and later production.
The original expression brief develops meaning, metaphor, composition, color and typography for a portfolio cover. The delivered local example is a project-owned learning-guide cover, not a personal preference or accepted portfolio commission.

## Current scope

30 records (27 imported seeds plus three practical records), 62 sources, seven passage-level pilot reviews, 12 competency-based modules, English lexical search and eight skills. Python's standard library is sufficient.
Existing Windows application adapters and methods are preserved. Photoshop live verification is blocked by explicit user decision, with no terminal or script substitution. Other application guides are not current connection proof.
Six authorized developments cover source review, original cover artifacts, identity operations, calibrated critique, retrieval and curriculum. Native/human cover acceptance, a real identity pilot and learner outcomes are not established. Independent final review is separate from software verification.

## Acceptance criteria

- English names and aliases retrieve the same known concept; type and medium filters remain available.
- No records are invented when nothing matches. Search scores do not measure aesthetic quality.
- Mixed matches disclose unmatched terms; constraints are not evaluated by lexical retrieval.
- Editable SVG and flat PNG delivery, AI pixel review, native production and human acceptance are separate gates.
- Source links and search work in relocated standalone skill packages.
- Updates preserve existing preferences and verify backup integrity.
- Sourced history, contemporary proposals and personal preferences remain distinct.
- `python scripts/check.py` passes. Live production evidence is recorded separately.

## Future scope

Unreviewed sources and future controlled production tests require their own evidence and authorization; this wave's Photoshop block remains in force.
No claim of complete global art coverage is made.
Tasks are managed through [GitHub Issues](https://github.com/ebnative/design-taste/issues) as the single source.
