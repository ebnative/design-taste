# Initial release scope

The supplied modular architecture guides the initial release: atlas import, learning path,
lexical retrieval, three knowledge skills and five Adobe production modules.
The first pilot translates personal expression into design decisions for a portfolio cover.
Next steps: re-review individual sources, enrich dates/geographies/works, test application connections while preserving
existing skills, then perform controlled installation and migration.
The initial release was subsequently saved as an independent project and published to GitHub.
Repository content and retrieval were then translated into English at the user's request.
Adobe application installation and moving user files remain outside this release's scope.
