# İlk sürüm kapsamı
Kullanıcının sağladığı modüler mimari esas alınmıştır. İlk teslim: atlas importu, öğrenme yolu,
TR/EN lexical retrieval, üç bilgi becerisi ve beş Adobe üretim modülü.
İlk pilot iş akışı: kişisel portfolyo kapağı için öz anlatımı tasarım kararlarına çevirme.
Sonraki aşamalar: kaynakları tek tek yeniden inceleme, tarih/coğrafya/eser verisini zenginleştirme,
uygulama bağlantılarını mevcut becerileri koruyarak test etme, ardından kontrollü kurulum/geçiş.
GitHub yayınlama, Adobe kurulumu ve kullanıcı dosyalarını taşıma bu yerel ilk sürümün parçası değildir.
