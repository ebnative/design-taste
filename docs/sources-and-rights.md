# Sources and rights

The first 27 records and 60 source entries were imported from a supplied research report.
Its access/review claims remain in source metadata; this release does not present them as independent verification.
Text, artwork, photography, data and font rights are separate. Books, artwork images and font files are excluded.
Keep historical claims, observable principles, contemporary proposals and personal preferences distinct.
When reviewing a new record, open the actual institutional page and record its source ID and review date.
Review content rights before public distribution. No open-source license has been selected for this package.
Upstream UI UX Pro Max code and datasets were not imported; its architecture provided inspiration.
English translation does not change the imported source-verification or rights status.
