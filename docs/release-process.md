# Distribution

Repository content is the source of truth. Installation packages are derived copies.
The installer bundles shared knowledge, workflows and search files into each skill,
so relocating one skill directory does not leave broken links to the repository.
Existing destinations are untouched by default; updates require `--update`.
Before updating, a full backup is hash-verified and private style/memory records are preserved.
The legacy Photoshop identifier is not automatically deleted or retired. Live verification is a separate migration step.
Production skills do not install applications or MCP connections. Without a live application test, production cannot be marked as passed.
Review rights, private data, provenance and current access status before publishing new content.
