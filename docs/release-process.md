# Dağıtım
Repo içeriği kaynak otoritesidir. Kurulum paketleri bunun türetilmiş kopyalarıdır.
Kurulum scripti her skill'e yalnız gerekli ortak bilgi/iş akışı/arama dosyalarını bundle eder.
Böylece tek skill klasörü taşındığında repo dışına çıkan kırık göreli yollar oluşmaz.
Kurulum mevcut hedefe varsayılan olarak dokunmaz; güncelleme için --update gerekir.
Güncelleme öncesi dosya hashleri doğrulanmış tam yedek alınır; özel style/memory kayıtları korunur.
Photoshop'un eski makine adı otomatik silinmez veya emekliye ayrılmaz. Canlı doğrulama ayrı geçiştir.
Üretim becerileri uygulama veya MCP bağlantısı kurmaz. Canlı uygulama testi yapılmadan production=pass olmaz.
Kamuya yayın öncesi haklar, kişisel veri, kaynak kökeni ve güncel erişim durumu ayrıca gözden geçirilir.
