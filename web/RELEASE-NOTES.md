# Public preview

This is an owner-approved preview of the current Design Taste website, not a completed acceptance release or an affiliated school programme. Existing lessons are frozen for this publication.

## Known limitations

- If playback is paused while the audio system is still resuming, pending playback may start afterwards. Until repaired, avoid rapid Play/Pause operations; stop playback and reload the page if needed. Download your project before reloading.
- After importing speech, standard timing/rights/gate exports can still describe the portable project as tone-only. Use the separate local-speech recipe and actual video export receipt to document the live recording. Do not treat those standard exports as a complete media-rights inventory or verified caption alignment.
- Recorded speech and its offset are held only in page memory and must be reimported after reload. Project JSON excludes audio bytes and local paths.
- Large compressed images can consume browser memory before dimension rejection. Use trusted, modest-size images.
- Comprehensive final keyboard, accessibility, browser and all-lesson/all-movement acceptance remains incomplete. Automated test success is not learner assessment, native Adobe proof or human acceptance.

Original teaching and diagrams are independent contemporary interpretations. Institutional sources are outbound references, not redistributed courses or endorsements. Source-review and rights statuses remain explicit. Private audio/video test fixtures, logs and backups are not included in the published site.
