01 / Pixel techniques

Technical operations change actual pixels, not the historical meaning of an image.

Use trusted, modest-size images. File size is checked before decoding; dimensions are checked after browser decoding. A highly compressed, huge image can consume memory before rejection. Source-decoder memory is not bounded by the 960-pixel working canvas.

Your image stays in this browser.

PNG, JPEG and WebP only, up to 20 MB, 12,000 pixels per side and 40 megapixels. Images are decoded locally, never sent to a server, saved in browser storage or included in a recipe. Working copies are limited to 960 pixels on the longest side. Invalid selections preserve the last valid reference.

The site has no analytics, account, CDN or upload endpoint. Source links navigate to external sites only when chosen. Reset discards the local working image; leaving the page also discards it. Downloaded files are saved only through your browser's normal download controls.
