# Design Taste: print workshop / exhibition catalogue

Provisional design direction; human acceptance and learner outcomes pending.
Derived from the actual UI UX Pro Max Quick Reference and repository-native static architecture; its search utility is unavailable, so no generated-search recommendation is claimed.

## Information architecture
Home introduces a read → observe → make → revise loop and original cover evidence. Academy groups modules 01–04 as Foundations (observation, color, type, historical literacy), 05–08 as Applied Practice (image, identity, series, editorial), 09–12 as Synthesis (time, narrative, critique). Every module exposes its canonical prerequisite/objective/artifact/criteria/revision/evidence contract. Atlas exposes every current record and all source entries, preserving claim-review and rights boundaries. Lab keeps six technical transforms separate from a movement-study catalog; five rendered approximations, others explicitly pending. Lesson and record URLs are shareable; exercises return to their originating lesson.

## Visual language and semantic tokens
The existing paper/ink/cobalt/rust identity is amplified through original cut-paper and overprint compositions, not an imported historical aesthetic. Home is Experience/Persuade: a vertical press sheet, inset working reference and staggered studio-directory rows replace the interchangeable card rhythm. Academy is Read: three plate crops introduce three levels, with serif lesson folios and readable expandable contracts. Atlas is Read/Experience: typographic catalogue entries and displaced row indents, with filters and claim status kept plain. Lab is Operate: registration graphics remain outside tools; double-rule image mounts frame real canvases, while native controls stay on quiet paper. All identity graphics are labelled original, never historical artwork or movement samples.

Original assets: `art/press-sheet.svg` (800 × 920) and `art/registration-strip.svg` (1200 × 260), self-contained vector geometry with no external requests. The existing `reference.svg` remains the functional Lab source and is unmodified. No downloaded art, fonts, dependencies, gradients, glass, animated ornament or historical-art claims.

## Interaction and accessibility
Semantic nav, headings, skip link, visible 3px focus rings, native labeled controls with minimum 44px targets. Navigation wraps on mobile, never hides behind hover or a drawer. Reading measure 70ch; grids collapse at 760px and reflow at 200% zoom. No animated art or flashing; respect reduced motion. Original and output canvases have descriptive text and side-by-side/single-view alternatives. Optical studies warn about discomfort. Empty/error/loading messages are plain and announced. No accounts, tracking or stored uploads. File decode is bounded and stale completions ignored; previous valid reference survives errors. PNG/JSON exports retain actual working dimensions and parameters, not press-ready claims.

## Integrated original-content slice
The shared `curriculum/studio.json` supplies original instruction, normalized geometry and five regions for Academy 01/02, De Stijl and Lab. A single SVG renderer reconstructs the simplified original; the unchanged 960×640 reference remains separate. Editable surfaces are 600×600 and the inspection viewport is genuinely 150×150. Desktop uses original-reference rail, dominant stage and native inspector; mobile puts the stage before controls. Same-size pinned/revised views, object selection, position/scale/fill, visibility, layer order, variants and a 30-snapshot undo/redo history are functional. The initial pilot remains preserved: version1 geometry/color state, legacy studies and its separate revised-reconstruction analysis. Renewed original-only scope now supplies consumers for every lesson and thirteen distinct movement constructions; those consumers do not certify completed learner work. An unchanged original-reference card embeds reference.svg unchanged with separate spatial overlays and observation/interpretation statements. The small document engine supplies exact-size typography, research cards, vector collage, identity uses, format series, eight publication pages, timed sequences and a traceable case study. Native SVG/Canvas, system fonts and the existing palette remain; no framework, protected assets or institutional-content import.

Native controls edit actual primitives, glyphs, masks, independent layers, shot holds/captions and position/scale endpoints. Browser timelines have explicit play/pause/scrub/static alternatives, guarded nonnegative rAF clocks, original PCM non-speech audio and SRT/WAV/timing outputs. Native WebM export is capability-qualified and produces a separate actual-source-hash/metadata receipt; frame counts, duration correctness, native operation and acceptance are not inferred.11 actual-speech alignment remains blocked. Default motion identity keeps the same arch construction and exact wordmark across shots. No autoplay or flashing.

Portable pilot schema/1 remains compatible. Original-only practice schema/2 has a400KB typed preflight and known ID/key/primitive/font/color/source-url allowlists, bounded finite geometry and no imported status authority or user-upload/media persistence. Failed imports/rendering/encoding retain work. Current/source/before/alternatives/journals are explicit artifacts, not mastery states. Outputs are prepared, never claimed saved before browser/user readback. Parent real-HTTP browser QA, independent review, native and human acceptance remain separate unclosed gates.

Color specimens lock the central patch to #808080 (RGB 128,128,128), use six independently editable surrounds and preserve the initial backgrounds in evidence. No difference is valid observation. Revision evidence requires a real geometry/background delta, not just a written claim. Retained evidence is not mastery, instructor acceptance, historical verification or print proof.

Only explicit downloads/import carry progress: no notes or image browser storage. Original-only `design-taste-studio/1` JSON is bounded to 200 KB, known IDs/keys, fixed 600 dimensions, typed finite geometry and inert hex colors; invalid imports retain prior state. Photos never enter this schema. Dirty navigation warns; resetting geometry requires confirmation and does not reset the pixel source. SVG exports contain editable primitives; PNG is browser-rasterized at 600×600. Each saved layout and each color specimen has individual SVG/PNG exports. An annotated SVG contains all retained statement text. Guided/Explore hides task guidance only, never rights/history limitations.

## Engineering and acceptance
Python standard-library build projects canonical JSON and Markdown deterministically. Static generated lessons are readable without JavaScript; client search and canvas use local native ES modules. Node is used only for developer tests, never needed to serve. No changes to source record statuses. Browser/mobile/keyboard/download acceptance is a separate parent-owned gate; software tests do not establish design mastery.
